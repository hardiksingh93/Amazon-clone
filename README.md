Amazon Clone — Frontend Practice Project

This repository contains an Amazon-inspired frontend clone created for learning and practicing HTML and CSS.

⚠️ Educational Disclaimer

This is a personal educational/practice project. It is not affiliated with, endorsed by, sponsored by, or connected to Amazon.com, Inc. or its affiliates.

The project is intended only to demonstrate frontend development skills such as:

- HTML5
- CSS3
- Flexbox
- Responsive layout concepts
- Basic UI design
- Git and GitHub

Features

- Amazon-inspired navigation bar
- Location section
- Search bar
- Account and orders section
- Shopping cart UI
- Hero section
- Product/category cards
- Footer navigation
- Hover effects

Technologies Used

- HTML5
- CSS3
- Font Awesome
- Git
- GitHub Pages

Project Purpose

This project was built as a frontend development practice project to improve UI implementation, layout design, and GitHub deployment skills.
